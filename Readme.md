

  RESPOSTAS DO EXERCICIO:
 
  a) Qual bloco está repetido?
 
  O bloco de calculo do valor bruto, desconto e valor
  liquido, além do printf que exibe cada produto.
  Esse bloco aparecia repetido para os quatro itens.
  Agora está centralizado na classe ItemPedido.
 
 
  b) Quais variáveis estão numeradas?
 
  descricao1, descricao2, descricao3, descricao4;
  valor1, valor2, valor3, valor4;
  qtd1, qtd2, qtd3, qtd4;
  kit1, kit2, kit3, kit4;
  bruto1, bruto2, bruto3, bruto4;
  abatimento1, abatimento2, abatimento3, abatimento4;
  liquido1, liquido2, liquido3, liquido4.
 
  Essas variáveis foram substituídas por atributos
  de ItemPedido e objetos individuais.
 
 
  c) Quais números mágicos existem e o que significam?
 
  0.15 = desconto de 15% para kits.
  0.08 = desconto de 8% para compras com 10 ou mais unidades.
  10 = quantidade mínima para desconto por quantidade.
  150.00 = valor mínimo para obter frete grátis.
  12.90 = valor do frete quando não há gratuidade.
 
  Esses valores foram transformados em constantes
  para facilitar a manutenção do programa.
